Sobre Moly

Nombre: Moly Music Player

Creación: HTML5 + CSS3 + JavaScript, en un único archivo.

Diseño: interfaz original neon, inspirada en reproductores modernos, pero sin copiar la interfaz de la imagen de referencia.

Programación: creada por ChatGPT para este proyecto. No requiere instalar una aplicación.

Música: Moly utiliza el reproductor oficial incrustado de YouTube para reproducir los videos disponibles. No descarga ni redistribuye las canciones. Si el HTML se abre directamente como archivo local (file://), YouTube puede bloquear el reproductor incrustado con Error 153; en ese caso debe abrirse desde una dirección web (HTTPS) o usarse el botón «Abrir en YouTube».

Guardado: la última canción elegida se guarda en el almacenamiento local del navegador. Al volver a abrir Moly, queda seleccionada pero pausada.

Clima: usa la ubicación que autorices en Chrome y consulta Open-Meteo. Si no das permiso, Moly no puede conocer con precisión tu ubicación.

Privacidad: la ubicación solo se utiliza desde esta página para obtener coordenadas y clima; el navegador controla el permiso.
